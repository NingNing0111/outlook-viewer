常用格式（4 段）

原始格式（7 段）

密码与 API 地址字段仅用于兼容输入，系统统一通过 Microsoft Graph 直连读取。也支持 —- 分隔符。请仅填写本人或已获授权的账户。

若已粘贴完整邮箱信息，可留空下方两项；系统会自动从粘贴内容中解析。刷新令牌仅发送给微软，不写入日志或数据库。
